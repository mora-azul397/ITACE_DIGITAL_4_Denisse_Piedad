# ITACE Digital 4 Denisse Piedad

## Nombre del proyecto
ITACE Digital 4 Denisse Piedad– Sitio web institucional del Plantel Reynosa.

## Descripción
Este proyecto consiste en el desarrollo de una página web institucional del ITACE Plantel Reynosa. Presenta información sobre la institución, su historia, especialidades, inscripciones, cursos y otros apartados relacionados con la comunidad escolar.

## Objetivo
Crear un sitio web moderno, organizado y fácil de utilizar que permita a los estudiantes y visitantes conocer mejor la institución y consultar su información.

## Tecnologías utilizadas
- HTML para estructurar el contenido.
- CSS para el diseño, los colores, las animaciones y la distribución de los elementos.
- js para realizar las nimaciones y la manera interactiva
- Git para registrar los cambios realizados durante el desarrollo.
- GitHub para almacenar y compartir el código fuente.

## Funcionalidades
- Menú de navegación entre los apartados.
- Portada principal de la institución.
- Información sobre la historia del ITACE.
- Presentación de las especialidades.
- Galería de imágenes.
- Presentación de los cursos.
- Información sobre inscripciones y cursos.
- Apartados informativos y recursos visuales.


## Instrucciones para ejecutar el sitio
1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Localizar el archivo `index.html`.
4. Abrirlo en un navegador web o utilizar la extensión Live Server de Visual Studio Code.
5. Verificar que las imágenes, los estilos y los demás recursos se encuentren en las rutas correctas.
